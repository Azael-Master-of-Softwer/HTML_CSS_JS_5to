# **HTML_CSS_JS_5to**
Descripción

Este repositorio contiene varios ejercicios y proyectos de práctica con HTML, CSS y JavaScript, correspondientes al nivel quinto (o quinto semestre/nivel) de aprendizaje web. Aquí explorarás archivos de estructura básica (HTML), estilos con CSS y elementos dinámicos con JavaScript.

Contenido del repositorio

Dentro encontrarás carpetas como:

HTML Y CSS/ → Proyectos centrados en maquetado y estilos.

HTML Y JAVA/ → Proyectos que combinan HTML con lógica, posiblemente en JavaScript o Java (según nombre).

AUTOBIOGRAFIA/ y AUTOBIOGRAFIA CON TODO/ → Ejercicios personales de tipo autobiografía que integran los conocimientos aprendidos.


## **Tecnologías utilizadas**

HTML (~ 80 %)

Python (~ 8.7 %)

CSS (~ 8.2 %)

JavaScript (~ 2.8 %)
